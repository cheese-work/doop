# doop feature map

One file per feature. Each has the same four sections. Drive one with `scripts/drive.mjs <run-dir> <name> <evidence-dir>`.

- [auth](auth.md) - sign up, session, `/api/me`
- [canvas](canvas.md) - create a canvas, open the editor at `/c/<id>`
- [pages](pages.md) - add a page in the Pages panel, survives reload
